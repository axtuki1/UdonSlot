# 機種エディタ

抽選表・配当表・ボーナス/RT・リール制御を1つの画面で編集し、制御ごとに「狙う出目」を並べるだけで、全押し順・全押下位置の滑りテーブルを自動生成するエディタです。
当選役の引込と非成立役の回避は自動で行い、デザイナーは出目の出し分けだけを指定します。

- 画面: `UdonSlot > 機種エディタ`
- 設計の保存先: `ReelDesignAsset`（`Create > UdonSlot > リール制御設計`、または画面の「新規」）
- 生成エンジン: `Editor/ReelRule/Core`（Unityに依存しない純C#）
- テスト: `Tests~/ReelRule`
- 出力: `ReelControlData`（基本テーブル＋停止位置の条件付きテーブル）と、`ReelControl` の割り当て表

抽選表・配当表・ボーナス/RT表はシーンのコンポーネント（`LotteryTable`・`PayoutTable`・`BonusTable`）を直接編集します。出目と制御の設定だけが `ReelDesignAsset` に入ります。

## 上部のバー

- **機種**: `ReelOutputController`（派生クラス可）。配列・有効ライン・配当表・抽選表・ボーナス/RT表はここから読みます。
- **設計**: `ReelDesignAsset`。「新規」で作ると、抽選表のフラグごとに制御が入った状態で始まります。
- **リール画像**: リールテクスチャを指定すると図柄を画像で表示します（3リールを横に並べ、各リールの1番を上にした画像）。
- **制御方式**: ボーナス優先／小役優先。
- **最大滑り**: 初期値は機種の `maxSlipCount`。
- **規格**: 6号機／5号機。ボーナスの払出・回数の上限チェックに使います。
- **リール配列**: ReelMaker を開きます。
- **⚠**: 警告と通知の一覧。押すと該当の画面へ移ります。
- **レポート保存**: 結果を Markdown に書き出します。
- **ベイク**: 下の「ベイク」を参照。

変更するたびに裏で再計算されます（「計算済み」と出れば最新）。

## ① 制御

### 割り当て

左の一覧は、抽選表のフラグ1つにつき1行です。行を開くと、ボーナスごとの「○○成立中」の行が出ます。

- 1つの行 = 1つの制御です。制御名を入力する必要はありません（ベイク時に `Cherry`、`Cherry_RedBB` のように自動で付きます）。
- フラグの行は、ボーナスが成立していないときの制御（通常）です。
- 「○○成立中」の行は、そのボーナスが成立している間にそのフラグを引いたときの制御です。新しく作った行は通常の行のコピーで始まります。右クリックの「通常の内容をコピー」で、いつでも通常の行に戻せます。
- 「○○成立中」の行には「ボーナスを揃える」の切り替えがあります。オフの行ではボーナスを当選役として扱わず、揃わないように止めます。
- 制御方式が小役優先のときは、小役のあるフラグの「○○成立中」は「-」になり、通常の行の制御を使います（小役優先では小役の成立時にボーナスを揃えないため）。ボーナス優先に戻すと選べるようになります。
- 抽選表の `Cherry_RedBB` のようなボーナス付きの行は、「Cherry の当選と同時に赤BBを成立させる」という意味です。制御は Cherry の行の「赤BB成立中」が使われます。

当選役は、そのフラグの当選役すべて（複数役の同時当選を含む）と、「ボーナスを揃える」がオンなら作動役です。役の編集は「抽選表で編集」から③で行います。

### 中央

押し順タブごとに2つの表示を切り替えます。

- **滑り表**: 第一〜第三停止のリールごとに、押し位置（1〜21）・滑り・決め手を表示します。第二・第三停止は、先に止まったリールの停止位置を選んで見ます。
- **出目マップ**: 第一停止の止まり位置を選ぶと、縦 = 第二停止の押し位置、横 = 第三停止の押し位置で、出る出目を色分けします。マスを選ぶと3×3のプレビューが出て、「滑り表」でその条件の滑り表へ移れます。

決め手のラベル:

| ラベル | 意味 |
|---|---|
| `○○引込` | 当選役を揃えるための滑り |
| `○○狙い` | 狙う出目に寄せるための滑り |
| `回避` | 非成立役・出してはいけないリーチ目を避けるための滑り |
| `最短` | どの候補も同じなので、滑りが少ないもの |
| `手動` | Advanced で手動指定した滑り |
| `回避不能` | 最大滑りでは避けきれない押し位置 |

### 右側

- **狙う出目**: どれかになる割合を最大にしたうえで、上ほど優先。小役の引込より先に効きます。基本目を狙う制御では、小役は狙う出目でだけ揃い、狙っていない基本目は出ません。右クリックで並べ替え・外す。リーチ目は②で「出てよい制御」にした制御でだけ追加できます。
- **この制御で出てよいリーチ目**: ②の設定の確認用です。
- **Advanced：滑り数の手動指定**: 「有効」にすると、滑り表の行をクリックして滑りを固定できます（「自動」で解除）。固定した位置も非成立入賞・リーチ目の漏れを毎回チェックし、問題があれば「手動指定による警告」に数えます。
- **結果**: 当選役・出目の割合と、チェック（非成立役の入賞・リーチ目・禁止目の漏れ・手動指定による警告）。割合は全押し順・全押下位置を等確率で押したときの値です。

## ② 出目

停止後の3×3の形に名前を付けて登録します。

- マスを選び、パレットの図柄をクリックすると「含む → 否定 → 指定なし」の順に切り替わります。「含む」は複数指定でそのどれか、「否定」はその図柄以外。何も指定しないマスは ANY です。
- **押し順**: すべて／左・中・右第一停止のみ。選んだ押し順のときだけ、この出目を使います。
- **種類**: **基本目** はどの制御でも出てよい形。**リーチ目** は「出てよい制御」にチェックした制御でだけ出ます。それ以外の制御では、全押し順・全押し位置で出ないことを保証します。**禁止目** は「出さない制御」にチェックした制御で出ないことを保証します（例：ハズレでのスイカテンパイハズレ）。禁止目は狙えません。
- **出し方**: **通常** は停止位置を問いません。**特定停止位置のみ** は3リールそれぞれの停止コマ（下段の番号、複数可）を指定します。リーチ目ミッションの組み立てに使えます。
- **表示可否**: リーチ目は出てよい制御、基本目は狙っている制御ごとに、出せる経路数（✓）か出せない理由（✗）を表示します。禁止目は出さない制御ごとに、出ない（✓）か出てしまう経路数（✗）を表示します。
- 配当表で移行図柄にした役は、その属性に応じて狙う出目・禁止目へ自動で入ります（「自動で入る出目」。個別に変更できます）。

## ③ 抽選表

`LotteryTable` を編集します。上で BET と、通常・各ボーナス作動中・各RTの抽選表を切り替えます。

- フラグごとに当選役（複数可）と、設定ごとの抽選比率を入力します。ハズレ（余り）の行は残りが自動で入ります。
- フラグの下に、ボーナス付きの行（例 `Cherry_RedBB`）を追加できます。そのフラグの当選と同時にボーナスを成立させる行です。
- 「ボーナス合算」はボーナスごとの成立確率、「選択合算」はチェックした行の合計確率です。
- 設定名は編集でき、設定の数は −／＋ で変えられます。

## ④ 配当表

`PayoutTable` を編集します。

- 役ごとに種別（小役・リプレイ・ボーナス・移行図柄）、図柄の組合せ、BET別の払出、停止順を設定します。
- 図柄は画像で表示し、クリックで複数選択（どれか1つで成立）できます。何も選ばないリールは ANY です。
- 有効ラインは3×3のカードで表示し、クリックで段を選び、BETごとに有効・無効を切り替えます。
- 移行図柄は払出0の役です（例: こぼし目）。RTの「図柄表示」の契機に使います。

## ⑤ ボーナス・RT

`BonusTable` を編集します。機種に無ければ「ボーナス・RT表を作成」で作れます。

- **役物**: 種別（SB・RB・CB・BB・MB）、作動役、作動中の抽選表、終了条件（払出・遊技・入賞）、規定BET、成立時のRT、終了後のRT。BB・MBは連続作動させる役物を選びます。規格の上限を超えると ⚠ が出ます。種別の横の「?」で各種別の説明が見られます。
- **CB**: 「すぐ止まるリール」を1つ以上選びます。CB作動中は制御表を使わずに止まり、どの小役が揃ってもかまいません。すぐ止まるリールは滑り1コマ以内で止まります（規則: 停止操作から75ms以内に停止）。
- **MB・CBの抽選表**: 空欄なら通常時と同じ表で抽選します。違う表を選ぶと ⚠ が出ます（作動中も小役・リプレイの確率は通常時と同じにする決まりのため）。
- **状態（RT）**: 状態ごとの抽選表と、G数で終わる場合のG数。状態0が基底の状態です。
- **図柄表示の移行**: 移行元の状態・契機の役・移行先。フラグを指定するとそのフラグのときだけ移行します。
- 「RTフロー図」で、ボーナス成立・作動・終了・図柄表示・G数消化による移行を図で確認できます。

ルール:

- ボーナスが成立中・作動中のときは、図柄表示による移行は起きません。
- 図柄表示で入ったG数付きのRTは、図柄表示では上書きされません。
- ボーナスに入ると、それまでのRTは上書きされます。
- MB作動中にRB・SBが成立すると、その遊技でMBが終わり、RB・SBは成立中として残ります（その遊技では揃えません）。MB作動中にBB・MBは成立しません。

## 滑りの決め方

各押下位置で、0〜最大滑りの候補を次の順に比べ、1つに決めます。

1. **出してはいけないものを出さない。** 非成立役と、その制御で出てよくないリーチ目・禁止目を、この後どう押されても避けきれる候補だけを残します。
2. **ボーナスを揃える。**「制御方式」がボーナス優先のときだけ、ここで引き込みます。
3. **狙う出目に寄せる。** まず狙う出目のどれかになる割合が高い候補を選び、差がなければ上の出目から順に比べます。基本目を狙う制御では、狙っていない基本目や、狙う出目以外の形での小役入賞も避けます（狙う出目にできないときは取りこぼします）。押し順を限定した基本目しか狙わない場合、ほかの押し順では小役を通常どおり引き込みます。
4. **小役を揃える。** 狙う出目がない制御と、リーチ目だけを狙う制御で引き込みます。同時に当選した小役は配当の多い順に引き込みます。押し順ベルは、配当表で15枚役に停止順を指定すれば、正解押し順で15枚役、それ以外で1枚役になります。小役優先のときは、この後にボーナスを引き込みます。
5. **滑りが少ない候補。**
6. 手動指定した押し位置は、その値で上書きします。

各段では「この後の押し順・押下位置が等確率だとして、最善に滑らせたときに揃う（その出目になる）割合」が高い候補を選びます。

狙う出目のない制御は、当選役の引込だけで決まります。狙う出目を入れると、その分だけ小役の入賞率が下がることがあります（例: スイカAは右下がり、スイカBは上段に寄せると、それぞれの形の出方がはっきり分かれる代わりに、取りこぼしが増えることがある）。

同じ設計と機種データからは、いつも同じテーブルが生成されます。

## ベイク

「ベイク」で、制御ごとに同じ名前の `ReelControlData` へ書き込み、`ReelControl` に割り当て表（フラグ × 成立中のボーナス → 制御名）を書き出します。その後シーンを保存してください。

- まだ無い制御は、機種の子に制御名の GameObject を作って `ReelControlData` を付け、`ReelControl` に登録します（`ReelControl` が無ければ機種と同じ GameObject に追加します）。
- 小役優先で「-」になっている行はベイクしません。

実行時は `ReelOutputController.GetReelControlFlagName()` が、抽選したフラグ（ボーナス付きの行なら元のフラグ）と成立中のボーナスから割り当て表を引きます。成立中の行が無ければ通常の行を使います。割り当て表が無い古いデータでは `controlNameFormat`（既定 `{flag}_{bonus}`）で名前を組み立てます。

## 今の制限

- 停止途中（第2停止時点のテンパイ形など）を条件にした指定はできません。
- 目押しの上手さや押し順の偏りは考慮しません。

## テスト

.NET SDK 8 があれば、Unityなしでエンジンを検証できます。

```
cd Packages/com.axtuki1.udonslot/Tests~/ReelRule
dotnet run -c Release
```

サンプル機種と実機（ASLOT-1）の配列で、非成立入賞0、引込率が総当たりで求めた最大値と一致すること、リーチ目が出てよい制御以外で出ないこと、ベイク後の配列を実機と同じ検索手順でたどった結果が生成結果と一致すること、割り当て表の作り方、などを確かめます。
